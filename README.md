# 图片查重 · ImageScout

本地离线找出「同一张图的不同裁剪 / 同场景不同构图」，并排对比、一键清理。
零第三方依赖，不联网，单文件 `ImageScout.exe` 双击即用。

## 功能

- **相似分组**：扫完自动分组，点一组就并排对比（代表图 ↔ 与它最像的那张）
- **全部图片**：列出所有扫到的图（包括没配对上的），每项都带小预览
- **认得出「不同裁剪」**：裁剪不变描述子 —— 裁过、压过、加过水印的同源图也归一组
- **一键清理完全重复**：字节级 100% 相同的图批量处理
- **画质标记**：NIQE 无参考画质评价，低清 / 质量差的图在列表里强调出来
- **删除 = 移到隔离夹**：不是真删，文件进扫描目录下的 `_隔离`，随时能捞回来，
  再扫也不会又冒出来
- **灵敏度三档**（严格 / 标准 / 宽松），可勾选含子文件夹
- 支持 PNG / JPEG / GIF / BMP / WebP / TIFF / HEIC / AVIF

## 怎么用

1. 从本页右侧 **Releases** 下载 `ImageScout.exe`
2. **双击运行** —— 不需要安装 Python，不联网
3. 点「添加文件夹」选照片目录 → 「开始扫描」→ 左边选一组，右边立刻并排对比

命令行也能直接给路径：

```bat
ImageScout.exe D:\照片          :: 直接把目录作为扫描源
ImageScout.exe a.jpg b.png      :: 或者直接给几张图片
```

## 使用要点

- 左边两个视图可切：**相似分组** 看分组、**全部图片** 看单张
- 图片上：**滚轮缩放**、**按住拖动**、**双击**用系统看图器打开
- **只看匹配区域**：把两张图对应的那块裁出来对着看（比在原图上找快得多）
- 复制操作一排按钮：复制图片 / 文件名 / 完整路径，以及定位到文件夹

## 源码运行（可选）

需要**带 Tkinter 的 Python 3**，无需安装任何第三方库：

```bat
python image_scout.py                :: 打开后自己添加文件夹
python image_scout.py D:\某目录
```
